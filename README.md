# 动日 · 运动手记

原生微信小程序，无第三方依赖。以清晰的今日记录、运动历史、数据统计三个分区记录每日运动。

## 使用

1. 使用微信开发者工具导入本目录，选择小程序项目。
2. `project.config.json` 默认使用游客 AppID 体验；真机预览、上传及发布请在开发者工具中配置自己的小程序 AppID。
3. 编译后点击“记录一次运动”，选择日期、类型、时长与感受，可填写 120 字备注。

支持补记、编辑、确认删除、今日运动时长、累计天数与时长、连续运动天数、最近七天柱状图。连续天数从今天起计算；今天尚未记录时从昨天起计算。

数据使用微信本地同步存储；不需要后端、登录、网络或密钥。清理小程序数据、卸载或更换设备可能导致记录丢失，不支持跨设备同步。读取失败时禁止新增，避免覆盖原数据。

## 验证

```sh
node --test tests/*.test.js
```

请在微信开发者工具中验证：首次空状态 → 新增今日记录 → 补记历史日期 → 编辑 → 取消/确认删除 → 切换统计 → 重新编译确认数据保留。检查 iOS/Android 安全区及小屏弹窗滚动。Node 测试覆盖数据校验、统计计算及存储保护，不能代替微信运行时 UI 验证。
