# 5 人办公室协作：一次部署，其他人用浏览器登录

选一台经常开机、连接办公室网络的 Windows 电脑作为主机。仅这台电脑需要 Python 和项目文件。其他四个人通过浏览器访问同一个地址，数据集中保存在主机，电脑和手机浏览器都可用。

## 从旧版本升级

1. 在旧网页点击“导出备份”。关闭旧服务窗口后，再把原来的 `data` 文件夹复制到一个安全位置作完整备份；里面可能包含业务数据。
2. 下载新版并解压到新文件夹，将原来的整个 `data` 文件夹复制到新版 `huadi-ops` 文件夹内。
3. 这次需要更新程序后端，不能只替换 `static`。不要让新旧服务同时使用同一份数据库。第一次运行会保留原内容、指标、线索和复盘，并升级数据库结构；如检测到旧数据库，会先保留升级备份。
4. 第一次设置好管理员账号后，再给同事创建账号。没有共享的默认密码。

## 主机如何启动

双击 `start-office.bat`。这等同于在项目文件夹执行：

```bat
python server.py --lan
```

如果用的是 Python Launcher，也可以执行 `py -3 server.py --lan`。保持命令窗口打开，允许最小化。

若 Windows 提示防火墙访问，请只允许当前可信的**专用网络**。如果办公室连接被标记为“公用网络”，请先确认是可信办公室网络，再在 Windows“设置 → 网络和 Internet → 当前连接 → 网络配置文件”中改为专用，或请网络管理员处理。主机建议连接稳定的有线网络，并将休眠设置为工作期间不自动休眠。

启动后，在**主机自己的浏览器**访问 `http://127.0.0.1:8765`，按页面提示创建第一个管理员，设置账号、显示名称及至少 10 个字符的密码。首次管理员只能在主机本地创建，其他同事不能从网络抢先注册。

## 给其余 4 人创建账号

管理员登录后打开“团队管理”，逐个创建同事账号：

- 管理员：管理成员、修改所有业务内容、恢复备份。
- 运营编辑：维护内容、数据、复盘、选题与线索，查看操作记录。
- 只读查看：查看业务数据和导出业务备份，不能修改。

建议 1 位管理员、4 位运营编辑；如有人只看汇报，可以给只读权限。各自使用独立密码；登录后可修改自己的密码。管理员可以停用离职账号、重置密码；无法禁用或降级最后一位有效管理员。

## 同事如何打开

1. 主机按 `Win + R`，输入 `cmd`，回车；运行 `ipconfig`。
2. 找当前连接办公室网络的以太网或无线网卡，记下它的 **IPv4 地址**。例如地址是 `192.168.1.25`。
3. 同事连接同一办公网络，在浏览器地址栏输入 `http://192.168.1.25:8765`（换成你们主机实际地址），用管理员创建的账号登录。

同事不能使用 `127.0.0.1` 访问主机，这个地址指向各自自己的电脑。只有主机运行一个服务，不需要每个人下载一份程序，也不要把 SQLite 文件放在共享文件夹供多台电脑直接打开。

主机地址可能在重启后变化。可请网络管理员为主机设置 DHCP 地址保留，方便长期使用固定网址。

## 日常协作

- 内容编辑中填写负责人、排期，推进制作、发布、复盘；所有人查看同一份数据。
- 列表会定期检查最新版本；正在输入或打开弹窗时会保留当前输入，避免把草稿替换掉。
- 保存时会检查数据版本。若期间已有其他同事保存，后提交的修改会被阻止并显示冲突。请先复制需要保留的草稿，关闭弹窗、刷新最新数据，再重新打开该内容核对后编辑。程序不会静默覆盖同事的更新。
- 目前采取整个工作区的版本检查，因此编辑不同内容也可能触发冲突。对 5 人团队属于保守保护；不是逐字实时协同编辑。
- “操作记录”显示谁在什么时候进行了什么操作。记录的是动作概述，不保存密码。
- 收藏、选题批次和去重记录为团队共享；一人点“换一批”后，其他人会看到共享批次。

## 备份与恢复

日常可在网页导出 JSON 业务备份。JSON 包含内容、指标、复盘、线索和选题，不包含登录密码、账号及会话。

只有管理员能恢复业务备份；恢复前程序会保存一份数据库备份到 `data/backups`。恢复业务 JSON 不会覆盖团队账号，但会替换当前业务数据。请安排大家暂停编辑，并确认恢复的是正确文件。

完整迁移主机时，停止服务后复制整个 `data` 文件夹，连同新版源码一起搬到新主机。完整数据库含账号密码哈希，请妥善保管。不要把 `data` 或备份上传 GitHub。

## 打不开时先检查

- 主机命令窗口是否仍开着？主机自己能否打开 `http://127.0.0.1:8765`？
- 主机是否休眠、断网或换了 IPv4 地址？
- 同事是否连接同一办公网，而非访客 Wi-Fi、手机流量或隔离子网？
- Windows 防火墙是否允许 Python 在专用网络接收连接？
- 端口 8765 是否被旧服务占用？先关闭旧窗口再启动新版。

该版本用于可信办公室内网，默认本机模式仍只监听 `127.0.0.1`，添加 `--lan` 才监听局域网。内网使用 HTTP；如果需要在公共网络、异地或不可信网络访问，需另行部署 HTTPS，不要直接做公网端口转发。
