# 抖音 API 接入申请与后续对接

本版本尚未连接抖音 API。创建开发者应用、获得对应接口权限、运营账号授权，是自动读取数据的前提。当前仍可在“数据监控 → 抖音”手动录入，选题推荐独立运行，不依赖 API。

## 你现在需要做什么

1. 用实际运营主体在 [抖音开放平台](https://open.douyin.com/) 注册，进入控制台完成开发者入驻及主体认证。个人或企业可获得哪些能力，以当前控制台为准；运营商业市场账号时优先使用实际运营主体。
2. 按用途选择控制台支持的应用类型，创建应用。用途可如实描述为：“花地湾古玩城新媒体运营工作台，授权读取自有抖音账号视频及统计，用于内容效果分析与复盘。” 小程序能力不会自动授予账号视频数据权限。
3. 在能力/权限申请中查找授权用户视频列表、视频数据等读取能力。按平台要求提交产品功能说明、使用场景、隐私政策、数据使用方式和其他材料。创建成功不代表接口权限已审批通过。
4. 配置 OAuth 回调及应用安全信息。正式回调应使用自己控制的域名；能否使用本机回调，由应用类型和审核要求决定，不能默认 `127.0.0.1` 可以过审。当前本地工作台可以保留，通过独立的合规回调服务完成授权也需根据平台规则设计。
5. 获批后，让实际运营账号完成官方 OAuth 授权。后端接收并保管令牌，处理到期刷新、撤销授权与错误提示，再按实际配额同步已授权的视频数据。

完成申请后，提供**应用类型及已获批的接口名称**即可继续开发对接。不要在聊天里发送 Client Secret、access token 或 refresh token；这些只应放在受保护的服务端配置中，不可提交 GitHub，也不应进入网页的 JSON 备份。

## 对接工作台时的数据边界

- 将平台视频 ID 绑定到本地内容计划，按授权范围读取列表与统计；先预览再更新，避免覆盖用户手工字段。
- 常见可读取字段包括播放、点赞、评论、分享，具体以获批能力和响应为准。
- 下载量不等于收藏量。API 未返回的指标应保留原值，不可按零覆盖。
- 有效招商咨询、看场、洽谈和成交属于业务跟进数据，需要另外记录，不能用点赞或评论推算。
- 每次同步应记录时间和来源、保留历史快照；遇到授权失效应提示重新授权，而不是显示过期数据为最新。
- 视频列表需要游标分页；同步频率与批量大小必须按你的应用配额设置，不承诺实时同步。

## 热门选题和账号数据是不同能力

授权本人账号的视频数据，不会自动获得全网视频搜索或实时热榜权限。若希望以真实趋势驱动推荐，还需要取得对应数据来源的使用权限，并保留来源和更新时间。

本版本选题页使用本地内容库和栏目实际表现排序。它提供“换一批”、筛选、收藏、执行步骤和加入计划，但不宣称是实时热榜或联网 AI。推荐库是有限的，耗尽会提示更换筛选条件；不会悄悄重复推送。
